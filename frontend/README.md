GHAR KA KHANA - Frontend (Static Site)
-------------------------------------

This folder contains the static frontend for GHAR KA KHANA. It is designed to be hosted on GitHub Pages, Netlify, or Vercel.

Usage:
- Update `script.js` API_BASE to point to your deployed backend API (e.g., https://gharkakhana-backend.onrender.com/api)
- Commit & push to your GitHub Pages repo (root or gh-pages branch)
- The site fetches dishes from backend and posts chef applications & orders to backend endpoints.
